# Осколки Героя

Демонстрационный прототип мобильной RPG для кейс-клаба. Игровой цикл: ежедневная награда → коллекция героев → карточная битва → колесо судьбы.

## Локальный запуск

```bash
npm install
npm run dev
```

## Сборка

```bash
npm run build
```

Проект подготовлен для автоматического деплоя на Netlify из ветки `main`.
